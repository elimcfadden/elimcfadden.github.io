About →

Takes that sound bold until you see the data

Shattered Backboard Analytics is an NBA-only writing and visualization project. The idea is simple: make an argument about how the league plays, then put the chart on the table next to it. If the numbers do not back the take, the take does not run.

Every visualization on the site is built from scratch — currently in Tableau, with Power BI, SQL and Python work planned as the project grows. Articles show up when the analysis is actually finished, not on a schedule.
